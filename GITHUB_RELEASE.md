# GitHub Release Notes

## AstraMark v1.0.0

Tiny Windows crosshair overlay with a compact settings panel, editable hotkeys, and real alpha transparency.

### Download

Download `AstraMark.zip`, unzip it, then run `Start_AstraMark.bat`.

### Requirements

- Windows
- Microsoft .NET Framework 4.x
- No Python required

`Start_AstraMark.bat` checks for .NET Framework and opens the official Microsoft download page if it is missing.

### Default Look

- Shape: Plus
- Size: 8
- Line: 2
- Opacity: 255
- X/Y offset: 0
- Outline: Off
